# Progetto – Sito web sulla sostenibilità
# Orogel: un modello di sostenibilità nel settore agroalimentare

Questo repository contiene il codice del mio sito web realizzato come **project work universitario**.  
Il sito ha l’obiettivo di comunicare in modo chiaro le attività messe in atto da Orogel (azienda presa come caso di studio) nell’ambito della **sostenibilità** e di rendere disponibili i **report di sostenibilità** in formato scaricabile.

---

## 📌 Cosa trovi nel progetto

Il sito è sviluppato utilizzando **HTML, CSS e JavaScript**.

All’interno del sito sono presenti le seguenti sezioni:

- **Hero**  
  Introduzione al tema della sostenibilità e alla filosofia aziendale.

- **Azienda**  
  Descrizione del modello cooperativo, del territorio e della filiera produttiva.

- **Sostenibilità**  
  Sintesi delle attività ambientali, sociali ed economiche.

- **Progetti green**  
  Approfondimento di tre progetti concreti legati a innovazione, ambiente e filiera agricola.

- **Report di sostenibilità**  
  Sezione dedicata al download del report (PDF) e alla spiegazione dei contenuti.

Il sito è **responsive** e ottimizzato per desktop, tablet e dispositivi mobili.
